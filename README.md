# Página Web

Projeto acadêmico desenvolvido para praticar conceitos de Git e GitHub e a organização de uma página web.

## Objetivo

Praticar o desenvolvimento de páginas web e usar o GitHub para organizar e controlar as alterações realizadas no projeto.

## Arquivos do projeto

- `index.html` — contém a estrutura da página web.
- `style.css` — contém a estilização visual da página.

## Tecnologias utilizadas

- HTML
- CSS
- Git
- GitHub

## Controle de versão

Durante o desenvolvimento deste projeto, foi utilizado o branch `melhoria-estilo` para adicionar a estilização da página.

Após a alteração, foi realizado um commit e criado um Pull Request para integrar as modificações à filial principal.
